# 考公刷题伪装 App

把考公题目伪装成一条普通的好友聊天，让人以为你在玩手机。



起因是某个朋友不能用电脑、又不想一直玩手机，想利用碎片时间刷题。所以搞了这么个多此一举的玩意，本质是为了让他**看起来没在学习**。

伪装形态最后定为**虚拟好友单聊**：低头打字回消息是最不引人注意的行为，而且聊天界面可以停留很久，不会像静止的屏保那样显得异常。

## 实现思路

**数据** —— 题目从题库（粉笔）接口实时拉取，一次一批，取到就整体落盘。剩余题目少于 3 道时后台预取下一批，断网或登录失效时继续消耗缓存。

**伪装** ——

- 题目作为对方发来的消息，你的答案作为发出的消息。题干一条、选项一条，过长的题目和消息会按照句号切割；消息间有短暂停顿。
- 打开时预置了一段聊天历史。空白的聊天窗本身就很可疑
- 日常掺进随机闲聊和表情包。一屏一屏的问答太可疑，扫一眼得像普通聊天
- 配色走微信的观感，顶部显示名是游戏好友的样子

**答题** —— 回复 `1`~`4` 或 `A`~`D`。答对回「对了」并**自动推送下一题**（减少操作）；答错回「不对，选 X」并**附解析**，停住等你发「下一题」。另有 `为什么` 单独看解析。

**渲染** —— 题干、选项、解析都是 HTML。实测标签只有 `p`、`img`、`br` 三种。图片分两类处理——公式图尺寸很小、要跟着文字排版，用 RN 自带的 `Image` 当行内元素塞进文本；整幅插图单独成行。

## 运行

```bash
npm install
npx expo start
```

打包走 EAS 云构建，本机不需要 Android 环境：

```bash
npx eas build --platform android --profile preview    # 产出可直接安装的 APK
```
